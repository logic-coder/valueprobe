## 本轮修订（2026-11-24，居中估值三规则）

这是当前工件对应的**最新**修订；下方各节是历史记录，数字以本节和仓库工件为准。

政策版本仍为尚未推送的 v3，不升 v4。三条通用规则统一替代此前的"单窗 + 50% 现金否决 + 固定正常化基数"：

1. **增速取两窗较慢者**。十年与五年窗口都存在时，点估计采用封顶 15% 后较慢的那扇；较快的那扇只抬高区间上沿，不进点估计。目的是防止一段正在褪色的十年高增速被承保下一个十年，同时保留较快窗口作为上行情景。
2. **现金背离在 2.5 倍以内取中点**。盈利估值与现金估值相差 50% 以上但比值不超过 2.5 时，发布价取两者中点，区间同时覆盖两者，标 `CASH_MIDPOINT`；比值超过 2.5 仍拒绝 `CASH_UNRECONCILED`。两套测量都是正数且数量级一致时，给中点比留空白更有参考价值。
3. **正常化基数明显滞后时改用最近年度**。当最近年度每股收益与多年正常化基数之比达到 `RECENT_BASE_LAG_RATIO = 2` 且最近年度自由现金流为正时，发布基数改用最近年度盈利与现金的中点，标 `RECENT_BASE_LAG`。阈值使英伟达（4.9 / 1.19 ≈ 4.1 倍）切换，而谷歌（10.81 / 5.8 ≈ 1.9 倍）、苹果（8.98 / 6.13 ≈ 1.5 倍）保留正常化基数。

## 修订记录：D64（2026-11-23，区间与体制规则）

政策版本仍为尚未推送的 v3，不升 v4。本轮只修正居中估计包络与体制标记的三处实现，不改点估计公式：官方基数仍是正常化盈利（M≈D），增速仍是单一干净长窗口，折现仍是全市场同一条 `max(10%, ceil(该企业报告币种十年期)+6)`，不为个股定制参数。现金 50% 否决、不编造维萨每股收益、本批不做无日期全量刷新，均保持不变。

具体三处：

1. 区间低值只用已披露的更差窗口。不再对稳健正增长一律纳入 0% 增速。低值至少包含折现 +2 个百分点、官方增速与官方终值；若五年窗存在且低于官方增速，再纳入该五年窗（负数窗按现有规则抬到 0 后可用 0%）。只有官方起点已是 0%、历史为负，或符号相反的体制不确定时，低值才以 0% 增速为更差窗口；且仅在体制不确定时并进终值 0 的衰退情景。
2. 仅五年窗且历史为负、官方增速已归零时，高值只移折现 −2 个百分点，不把增速发明为 15%。仅当五年窗为正且作为官方窗时，高端才可向 15% 承保上限加宽。十年窗负历史（佳品零件）不因短历史顶帽。
3. 窗口冲突以符号相反为主。符号相反仍标 `REGIME_UNCERTAIN` 并加宽区间。双窗同号即使相差 ≥8 个百分点，也只把另一窗纳入包络，不标体制不确定，不并进终值 0，不升级为 `UNSTABLE_BASE_REGIME`。十年窗或五年窗本身为负仍标体制不确定。`UNSTABLE_BASE_REGIME` 仍只在体制不确定且最近一期报告每股收益不为正时触发。

## 基数、门禁与二阶、三阶影响

只加「现金偏离 50% 就拒绝」、不改基数，会把腾讯这一类已经接近阈值的名字误伤掉。本版先改基数：腾讯官方基数从 30.5475 港元（TTM）变为 20.5183 港元（正常化收益与三年现金中点），发布值从 611.45 降到 410.7，剩余现金差距落在 25–49%，因此保留发布并标 `CASH_DIVERGENCE`。

一般公司的中点，是在无法观察维护性资本开支时对 1986 年所有者收益的夹逼：自由现金流扣尽全部资本开支，收益不扣增长资本开支，中点不偷偷选定维护性份额。三年现金窗口必须齐全，不能把两年平均成假中位数。空气化工产品这一类现金不完整的名字只依赖正常化每股收益。金融机构只用正常化每股收益，因为银行的自由现金流不是所有者收益。

资本开支较重的成长公司会得到较低的发布值，这是设计：英伟达从 98.08 美元降到 36.46 美元，苹果从 179.75 美元降到 132.03 美元，台积电从 213.18 美元降到 125.1 美元。安全边际和对比排序都会随之改变；这是一次政策升版，不是静默刷新。

币种折现率仍是向上取整加 6 个百分点，所以 A/H 两地官方值仍会因人民币 8% 对港币 12% 差大约 14%，这不是新的缺陷。区间上沿在 8% 或 12% 加减 2 个百分点时仍然有限。

## Visa 每股收益与报价日期遗留

已拉取并检查 Visa 的官方 companyfacts（CIK 0001403161）。其中没有未带维度的 `EarningsPerShareDiluted` / `EarningsPerShareBasic`，也没有加权平均股本概念；`companyconcept` 对稀释每股收益返回 404。同期 10-K 实例（例如 2026-11-05 的 `v-20260930_htm.xml`）里这些数字是有的，A 类股稀释每股收益约为 12.32 / 10.20 / 9.73 美元，但都挂在股份类别轴上，SEC companyfacts 不收录带维度的事实。解析器新增了对 `USD/share` 单数单位的接受，但不会从净利润除以股本编造每股收益。已提交的 `public/data/NYSE-V.json` 年度每股收益仍为空，本批不写入虚构数字。D56 当时因为三年现金齐全，官方基数曾回退为现金 11.4947 美元，条目以 `NO_GROWTH` 拒绝。D60 废除中点并停止把现金当作官方基数后，现行工件为 `NO_EPS` 加 `NO_GROWTH`。解析器仍然不会从净利润除以股本编造每股收益，本批也不写入虚构数字。

全部 51 只港股、50 只 A 股和 49 只美股（含苹果）快照有价格和基本面日期，却没有 `quote_as_of`，所以 150 条官方记录仍带 `QUOTE_DATE_UNKNOWN`，`STALE_PRICE` 不会被触发。根因是刷新路径在缺少 `f124` 时可能写入无日期的指示报价。代码已改为：没有真实报价日期就不得写入或更新价格，缺失 `f124` 时改用带日期的 K 线收盘价，不编造今天，也不用基本面 `as_of` 回填。已提交的 500 个快照没有网络报价刷新就不能获得真实日期，本批不在文件里编造日期。这一遗留要等到以后一次带日期的刷新才会消失；`verify:data` 对此发出警告，但不只因为这 150 个既有名字而阻断本政策发布。

## 发布与回退

本批为离线 `rebuilt`，利率与快照日期沿用既有文件。`v2.json` 字节未改。回退政策时须把 `POLICY_VERSION` 与 `POLICY_V1_HASH` 一并恢复到 v2，并恢复 manifest 与发布状态；不要用研究分支的 v3 工件替代。首次从前端升级时，已经打开的旧标签页需要刷新。v3 前端遇到不兼容的工件会拒用并尝试刷新一次。
