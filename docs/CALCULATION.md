# 度量框架

估值记录不是只有一张表：它可以回答“这个判断后来怎么样”。度量层同样按
[wealthfolio](https://github.com/wealthfolio/wealthfolio) 的 `crates/portfolio-engine`
语义写：**每个指标要么是一个数，要么是 `null` 加一个稳定原因**，界面显示 `n/a` 与原因，
而不是 `NaN` 或 `Infinity`。公式内核 `src/lib/dcf.js` 不在这条链上，红线不变。

## 文件

| 文件 | 作用 |
| --- | --- |
| `src/lib/arith.js` | 有界算术：越界返回 `null`，零除返回一 `null` |
| `src/lib/measure.js` | 价值回报 / TWR / XIRR / 回撤 / 波动率 + 质量状态 |
| `src/lib/fx.js` | 展示货币汇率（ECB 日频参考价，两镜像 + 缓存 + 过期兜底） |
| `src/lib/archive.js` | 记录存取与“记录 → 度量输入”的转换 |

## 两种口径

- **价格口径**（记录里没有股数）：只按价格序列算价值回报与风险；XIRR 标 `不适用`
  （没有资金流），并给 `PRICE_ONLY` 提示。
- **持仓口径**（记录填了股数）：点位＝股数×价格，股数变化折算为外部资金流，
  TWR 用资金流修正，XIRR 解真实资金流。

## 公式

设相邻点位 `V[t-1]`、`V[t]`，区间流入 `in`、流出 `out`：

```
step    = (V[t] + out - V[t-1] - in) / (V[t-1] + in)
TWR     = Π (1 + step) - 1
XIRR    = 解 NPV(r) = Σ cf_i / (1+r)^(days_i/365.25) = 0（二分，-99.9999% 起，上界倍增）
回撤     = min((累计 / 历史峰值) - 1)，同时记录峰值日、谷底日、修复日、持续天数
波动率   = 对数收益样本标准差 × sqrt(每年样本数)，每年样本数由实际覆盖天数推出
年化     = (1 + 总回报)^(365.25 / 天数) - 1，跨度不足 30 天不给年化
```

所有乘除走 `arith.mul/div`：绝对值超过 `1e15`、除数为 0、结果非有限都判为不可用并记原因。

## 质量状态与原因码

状态：`ok` / `partial` / `no_data` / `not_applicable`。

| 原因码 | 含义 |
| --- | --- |
| `TWO_POINTS_REQUIRED` | 至少两条点位 |
| `NON_POSITIVE_START` | 起始值非正 |
| `NEGATIVE_DENOMINATOR` | 区间基数非正（存疑区间） |
| `OUT_OF_RANGE` | 数值越界 |
| `NO_SIGN_CHANGE` | 资金流同号，IRR 无解 |
| `NO_CONVERGENCE` | IRR 不收敛 |
| `ANNUALIZATION_TOO_SHORT` | 跨度太短不给年化 |
| `PRICE_ONLY` | 价格口径，IRR 不适用 |
| `NO_RETURNS` | 没有可用收益步 |

浮点噪声按相对误差处理（峰值判定用 `1e-12` 容差），避免 0.9×1.3333 这种步长把修复日判丢。

## 与展示货币的关系

展示货币只影响**只读结果**（`CALCULATION` 之外的 `DEVIATIONS` D6）：换算加 `≈` 前缀，
缺汇率显示 `≈ n/a`；可编辑输入始终是原币。度量数字始终按原币计算，不参与折算。

## 测试

`tests/unit/{arith,measure,fx}.test.js` 覆盖越界拒绝、资金流修正、回撤日期、年化门槛、
IRR 收敛与不收敛、缺失汇率。E2E 只验证界面显示 `n/a` 与原因，不重复算公式。


## 敏感性矩阵

中心为当前折现率/增长率，两轴各 ±2 个百分点（折现率夹在 0–50、增长率夹在 -20–60）。
头条和敏感性矩阵用同一套模型。界面上的「每股折现」是 `presentValue`：增速从第一阶段线性降到第二阶段，两段之后按终值增速做一次永续，资本化增速不超过折现率减 2 个百分点。没有可用历史增速时留空，不代填。美股快照与 A/H 一样给出 10/5/1 年窗口。企业自由现金流还没减净债务，不拿来折现。港股 `invest` 口径（经营现金流减去投资现金流出）不承诺可在本站展开，快照只存了结果数，构成项未拆开列示；核对请看财报原文。默认仍按每股收益估值，并在界面上明确这不是股东自由现金流。银行、保险、券商默认是 `residualIncomeValue`：净资产收益率逐年降到折现率，价值是账面加上这段超额收益的现值。回报一直保持时的 `enduringBookValue` 按数值落到区间的一端，回报已经低于折现率时它在下沿。页面可以改算法。主结果下面的区间，一般公司来自折现率上下 2 个百分点。`calGr2fv` 仍是增速不变的有限年金，只留给对照测试。非有限结果记 `null` 并显示 `n/a`。

- 实现：`src/lib/sensitivity.js`（`buildSensitivityGrid`、`marginBucket`）。
- 着色阈值（安全边际 = 1 − 价格 / 内在价值）：≥30% 淡绿、≥0 更淡的绿、≥-20% 黄、其余红。
- 倍数对照（`src/lib/multiples.js`）：当前倍数 = 价格 / 每股基数，隐含价 = 基数 × 目标倍数，
  与 DCF 内在价值的差以百分比列出；基数缺失即 `n/a`。非金融公司另有一条固定的 12 倍现行利润对照，表示利润不再增长时大约值多少，不进入内在价值；银行模型不显示。单测 `tests/unit/multiples.test.js`。

- 情景预设（`src/lib/scenarios.js`）只做固定增量：牛市 折现率 −1 / 增长率 +2 / 第二阶段增速 +1，
  熊市取反；折现率仍夹在 0–50。切「基准」恢复进入情景前的那组数（单测 `tests/unit/scenarios.test.js`）。

- 默认折现率是现金流币种的当地十年期国债收益率向上取整再加 6 个百分点。美元也用十年期国债，不用存量票息均值（历史上的 `5.14`、`3.399` 等一律不得作为利率或兜底）。港币因金管局十年期基准序列已中断，使用美元十年期作为代理并在界面标明。取不到当地利率时回退为 8%，并写明来源，不会静默改用美债；随包兜底文件是 `src/data/bundled/risk_free.json`，已删除的 `latest_indicator.json` 不得恢复。显示币种只影响读数，不改变折现率。自选和对比页按每只股票的币种分别取利率。可先用「推导」对话框按无风险 + β × 股权溢价 + 规模溢价算好再填入（`src/lib/wacc.js`，
  单测 `tests/unit/wacc.test.js`）；填进去的值仍走 0–50 的夹取。

- 单测：`tests/unit/sensitivity.test.js`（中心格等于当前模型的头条、边界夹取、非有限格）；E2E：
  25 格、中心格等于头条内在价值、改折现率后矩阵跟随。

## 公开口径 v1

页面上的发布值由 `src/lib/policy.js` 的 `policyValue()` 决定，不再由表单默认值直接发布。口径参数与拒绝/警告语义见 `POLICY.md`，这里只记它对计算的影响：

- 模型：一般公司 `presentValue`（两期折现 + 有上限的永续），金融机构 `residualIncomeValue`（账面收益逐年降到折现率）。基数固定为每股收益；自由现金流仍是股票页的对照，不进入发布值。
- 窗口与默认：`DCF_DEFAULTS` 的两段各 10 年、终值增速 4%；历史增速窗口 10 年、承保上限 15%（`MAX_UNDERWRITTEN_GROWTH`）。没有历史增速时发布值为 `null` + `NO_GROWTH`，不代填；负增长照常出值并加 `NEGATIVE_HISTORY_GROWTH`。
- 折现率：`ceil(当地十年期国债收益率) + 6`，再夹到 0–50（`policyDiscountRate()`）。港币现金流用美元十年期作代理；取不到当地利率时用 8% 兜底并标 `RATE_FALLBACK`。折现率跟随报价/现金流币种，显示货币不改它。
- 区间：同一模型把折现率上下浮动 2 个百分点（`POLICY_V1.band.discountSpread`）；金融机构的上沿是 `enduringBookValue`。头条是 `mid`，终值占比 `terminalShare` 一并披露。
- 价格：只进入安全边际；缺失给 `PRICE_MISSING`，过期给 `STALE_PRICE`，都不改内在价值；基本面过期给 `STALE_DATA` 也不拒绝出值。
- 一致性：`buildDefaults()` 与 `policyValue()` 对同一快照给出同一组输入（EPS、增速、折现率、两段窗口），由 `tests/unit/policy.test.js` 的默认输入对齐用例锁住；页面默认参数与发布值文件因此不会分叉。
- 自选、对比与方法页读发布值文件；股票页按同一组默认输入在本地计算（seed 对齐测试锁住），不再显示重复的发布值面板。刷新与校验见 `POLICY.md`。
