# 度量框架

估值记录不是只有一张表：它可以回答“这个判断后来怎么样”。度量层同样按
[wealthfolio](https://github.com/wealthfolio/wealthfolio) 的 `crates/portfolio-engine`
语义写：**每个指标要么是一个数，要么是 `null` 加一个稳定原因**，界面显示 `n/a` 与原因，
而不是 `NaN` 或 `Infinity`。公式内核 `src/lib/dcf.js` 不在这条链上，红线不变。

## 文件

| 文件 | 作用 |
| --- | --- |
| `src/lib/arith.js` | 有界算术：越界返回 `null`，零除返回一 `null` |
| `src/lib/measure.js` | 价值回报 / TWR / XIRR / 回撤 / 波动率 + 质量状态 |
| `src/lib/fx.js` | 展示货币汇率（ECB 日频参考价，两镜像 + 缓存 + 过期兜底） |

度量层直接接受带日期的观察序列（点位、资金流），由调用方组装输入。早期文档里的 `src/lib/archive.js` 已不在本仓库，不再作为记录存取层。

## 两种口径

- **价格口径**（记录里没有股数）：只按价格序列算价值回报与风险；XIRR 标 `不适用`
  （没有资金流），并给 `PRICE_ONLY` 提示。
- **持仓口径**（记录填了股数）：点位＝股数×价格，股数变化折算为外部资金流，
  TWR 用资金流修正，XIRR 解真实资金流。

## 公式

点位是当日**收盘**：`value` 已含当日资金流之后的价值。资金流记在当日起始，同日多笔先按净额合并；首日资金流已计入 `value[0]`，不再重复记。若首个点位取自资金流之前，传 `firstValue: 'before'`，净额并入期初余额与 XIRR 起点。

设相邻点位 `V[t-1]`、`V[t]`，区间流入 `in`、流出 `out`：

```
step    = (V[t] + out - V[t-1] - in) / (V[t-1] + in)
TWR     = Π (1 + step) - 1
XIRR    = 解 NPV(r) = Σ cf_i / (1+r)^(days_i/365.25) = 0（二分，-99.9999% 起，上界倍增）
回撤     = min((累计 / 历史峰值) - 1)，同时记录峰值日、谷底日、修复日、持续天数
波动率   = 对数收益样本标准差 × sqrt(每年样本数)，每年样本数由实际覆盖天数推出
年化     = (1 + 总回报)^(365.25 / 天数) - 1，跨度不足 30 天不给年化
```

所有乘除走 `arith.mul/div`：绝对值超过 `1e15`、除数为 0、结果非有限都判为不可用并记原因。

## 质量状态与原因码

状态：`ok` / `partial` / `no_data` / `not_applicable`。

| 原因码 | 含义 |
| --- | --- |
| `TWO_POINTS_REQUIRED` | 至少两条点位 |
| `NON_POSITIVE_START` | 起始值非正 |
| `UNKNOWN_FLOW` | 资金流日期没有对应点位（首个点位之前或两点之间）；TWR、XIRR 与风险一并置空 |
| `NEGATIVE_DENOMINATOR` | 区间基数非正（存疑区间） |
| `OUT_OF_RANGE` | 数值越界 |
| `NO_SIGN_CHANGE` | 资金流同号，IRR 无解 |
| `NO_CONVERGENCE` | IRR 不收敛 |
| `ANNUALIZATION_TOO_SHORT` | 跨度不足 30 天不给年化（非致命，比值照给） |
| `PRICE_ONLY` | 价格口径，IRR 不适用 |
| `NO_RETURNS` | 没有可用收益步 |

浮点噪声按相对误差处理（峰值判定用 `1e-12` 容差），避免 0.9×1.3333 这种步长把修复日判丢。

## 与展示货币的关系

展示货币只影响**只读结果**（`CALCULATION` 之外的 `DEVIATIONS` D6）：换算加 `≈` 前缀，
缺汇率显示 `≈ n/a`；可编辑输入始终是原币。度量数字始终按原币计算，不参与折算。

## 测试

`tests/unit/{arith,measure,fx}.test.js` 覆盖越界拒绝、资金流修正、回撤日期、年化门槛、
IRR 收敛与不收敛、缺失汇率。E2E 只验证界面显示 `n/a` 与原因，不重复算公式。


## 敏感性矩阵

自填参考报价更新安全边际和报价隐含的增速，保留默认估值、估值区间和依据。修改每股收益、增长率、折现率或模型后，个股页显示试算结果。默认估值的保守情景继续以公开假设作比较，柱长共用同一刻度。

中心为当前折现率/增长率，两轴按整数点各向外扩 2 格，越界点丢弃（折现率限 0–50、增长率限 -20–60）。格子因此不是固定的 25 格：边界处可能少于 25 格，中心格始终保留，且同一轴不重复。
头条、敏感性矩阵和反推用同一个有效终值增速。它取终值输入与折现率减 2 个百分点的较小值。第一阶段线性淡出到该增速，第二阶段和续营也采用该增速。第二阶段有限价值与续营价值分开列示。触发封顶时，调整折现率可能同时改变采用的增长假设。同参数的 v1 和 v2 跨界结果见 [RELEASE_V2.md](RELEASE_V2.md#终值区间与冻结对照)。

没有可用历史增速时留空。美股快照与 A/H 一样给出 10/5/1 年窗口。企业自由现金流尚缺净债务桥接时不参与股权折现。港股 `invest` 口径取经营现金流减投资活动现金流出，构成项可查财报。普通公司默认采用 EPS。REIT 与炼化保留盈利折现输入，仅供试算，直到行业估值口径完成复核。

银行、保险和券商的剩余收益估值为账面价值加显式期超额收益。净资产收益率逐年降到折现率，区间上下调整折现率时也会相应改变收敛目标。所有区间使用各自同一模型。无效端点留空，区间可以是单侧。旧 `calGr2fv` 与 `calculateReverse` 为定增长有限年金对照，页面反推使用 `impliedGrowth`。非有限结果显示为 `n/a`。

- 实现：`src/lib/sensitivity.js`（`buildSensitivityGrid`、`marginBucket`）。
- 着色阈值（安全边际 = 1 − 价格 / 内在价值）：≥30% 淡绿、≥0 更淡的绿、≥-20% 黄、其余红。
- 倍数对照（`src/lib/multiples.js`）：当前倍数 = 价格 / 每股基数，隐含价 = 基数 × 目标倍数，
  与 DCF 内在价值的差以百分比列出；基数缺失即 `n/a`。非金融公司另有一条固定的 12 倍现行利润对照，表示利润不再增长时大约值多少，不进入内在价值；银行模型不显示。单测 `tests/unit/multiples.test.js`。

- 情景预设（`src/lib/scenarios.js`）只做固定增量：牛市 折现率 −1 / 增长率 +2 / 第二阶段增速 +1，
  熊市取反；折现率仍夹在 0–50。切「基准」恢复进入情景前的那组数（单测 `tests/unit/scenarios.test.js`）。

- 默认要求回报是全市场同一条规则：`max(10%, ceil(该企业报告币种十年期国债收益率) + 6)`。不为单只股票或某一企业定制折现率、WACC 或 beta。收益率为零或负时仍是观测值、不改回退，但算出的折现率不会低于 10%：0 → 10%，−2.5% → 10%，−100% → 10%。先取整加 6，再套 10% 下限，最后夹到 0–50；只有缺失（`null`/空串/非有限数）才回退 10% 并标 `RATE_FALLBACK`。官方发布值因此不会再用 0% 折现。美元也用十年期国债，不用存量票息均值（历史上的 `5.14`、`3.399` 等一律不得作为利率或兜底）。报告币种为港币时，因金管局十年期基准序列已中断，使用美元十年期作为代理并在界面标明。报告币种为人民币时只用人民币利率，不会静默改用美债。取不到该币种利率时回退为 10%，并写明来源；随包兜底文件是 `src/data/bundled/risk_free.json`，已删除的 `latest_indicator.json` 不得恢复。显示币种只影响读数，不改变折现率。自选和对比页按每只股票的报告币种分别取利率。个股页「推导」对话框仍可按无风险 + β × 股权溢价 + 规模溢价算好再填入试算（`src/lib/wacc.js`，
  单测 `tests/unit/wacc.test.js`），那只是手动试算，不是官方发布折现；填进去的值仍走 0–50 的夹取。

- 单测：`tests/unit/sensitivity.test.js`（中心格等于当前模型的头条、边界夹取、非有限格）；E2E：
  内区 25 格、边界少于 25 格、中心格等于头条内在价值、改折现率后矩阵跟随。

## A/H 对照

方法页公开 9 组 A/H 对照，只做差异归因，不改写任何一方的发布值。H 股的 EPS、账面值和估值先按 `listingGroups` 的汇率折成 A 股币种，再计算 EPS、增长、账面值和折现率差。原因码：`FX_MISSING`、`PERIOD`、`EPS_MISSING`/`EPS_BASIS`（>5%）、`GROWTH_MISSING`/`GROWTH`（>2 个百分点）、`BOOK_MISSING`/`BOOK_BASIS`（>5%）、`RATE_MISSING`/`RATE_CURRENCY`（≥1 个百分点）。前六项决定 `aligned` / `input-mismatch`，折现率差只披露原因。规则上折现跟随各上市的报告币种，同一企业在报告币种与报表相同时应得到同一折现；不把折算后估值相等写成跨树契约，也不为某对 A/H 写特例参数或替部分 H 股捏造人民币报告币种。当前已提交的港股快照没有经核验的 `reporting_currency`，读时回退报价港币并代理美元，因此已对齐组在当前利率下大约差 1 个百分点（人民币 10% 对港币/美元 11%；美元十年期 4.85，asOf 2026-11-25，ceil+6=11）。这是现行收益率加上报告币种数据缺口，不是政策要保留的币种裂缝。一方未估值时状态是 `not-valued`。

`aligned` 只说明 EPS、增长和财报期间足以对照，不说明估值相等。`valueDiffPct` 为负表示折成 A 股币种后的 H 估值更低；负值同时包含汇率、折现率（在报告币种尚未核验时）与窗口差，不能单独当作汇率效应或可交易折价。

单测：`tests/unit/data-contract.test.js`（比亚迪与工行的差异桥、原因码、折后值）。

## 公开口径 v3

页面上的发布值由 `src/lib/policy.js` 的 `policyValue()` 决定，不再由表单默认值直接发布。口径参数与拒绝/警告语义见 `POLICY.md`，这里只记它对计算的影响：

- 模型：一般公司 `presentValue`（两期折现 + 有上限的永续），金融机构 `residualIncomeValue`（账面收益逐年降到折现率）。基数是可重复盈利：官方观察使用原始年度 `eps_without_nri`，不构造调整后每股收益。含重大非经营项目或质量未知的年份只按 0.25 降权，且不得用于确认台阶。通常取最近最多五年完整财年的近因加权。近十二个月盈利只展示，不回退成正式基数。最近两年都必须是干净年份、且确认数据完整时，改用最近三年加权值（`PERSISTENT_STEP_BASE`）；现金基数仅在现金确认路径通过时同步改用最近三年现金流中位数。跨周期均值只作为研究诊断，不再作为正式基数，也不再发出 `THROUGH_CYCLE_BASE`。美股年份只有明确的正面搜索证据才能把 N 记为 0 并判为干净；标记缺失、null 或显式未搜索均为未知。非美股未搜白名单质量口径（C）是按上市地给出的显式例外。没有干净完整财年可形成正基数时拒绝（`BASE_QUALITY_INSUFFICIENT` 或既有的 `NO_EPS` / `NON_POSITIVE_EPS`）。若最新年度只是质量未知、同一财年且日期明确的现金为正、且为非金融企业，则取该年每股收益与现金中位数的较低者（`BASE_CASH_CONFIRMED`），不再向上取中点；上一年度或日期缺失的现金不得用来清除质量拒绝。维护性资本开支按折旧摊销计（M≈D），因此所有者收益等于该正常化收益。`normalizedEarningsBase()` 本身只返回盈利数字，并不混入现金；现金是对照输入。两边都能形成正估值且对称差距在 50%–200% 时，公开值取两套估值的中点（`CASH_MIDPOINT`，`baseKind` 为 `midpoint`）；差距不到 50% 时仍以盈利侧为主；超过约三倍（>200%）以 `CASH_UNRECONCILED` 拒绝。金融机构的剩余收益路径不用现金流中点，也不走跨周期硬触发。快照缺少折旧摊销时，所有者模型加 `OWNER_BASE_GAP`（只披露，不拒绝）。`inputs.epsLatest` 保留最近报告每股收益，`epsNormalized`、`cashMedian` 以及折旧摊销 / 股份支付每股（若有）同步列出。基数与最近报告相差 ≥25% 加 `NORMALIZED_EPS`。这些字段只作披露，不改基数定义。显式 `0` 与 `'0'` 仍触发 `NON_POSITIVE_EPS`。
- 窗口与默认：`DCF_DEFAULTS` 的两段各 10 年、终值增速默认 4%；历史窗口由 `officialGrowth()` 决定（与页面播种、自选默认值共用）。两扇已披露干净窗口都存在时，先各自经过 0% 下限与 15% 上限，取较慢的一扇，再与可持续增速 g* = max(0, RR × ROE) 取更慢者作为发布起点（金融机构不走留存硬约束）。只有一扇窗口（包括仅有五年历史）时就用那一扇，仍受同一套上限约束。五年单独窗口也不再另设 10% 硬上限，只标 `SHORT_HISTORY`，不再把区间向 15% 加宽。无窗但有报告盈利且基数为正时起点 0%、终值仍 4%。任一窗为负，或十年与五年窗口符号相反时，标 `REGIME_UNCERTAIN`；同向差距不再把未采用的更快窗口纳入区间。负历史的点估计是起点 0%、淡出到默认 4%，不再把终值机械置 0。体制不确定且最近一期每股收益不为正时以 `UNSTABLE_BASE_REGIME` 拒绝。一年增速不进入发布值，也不设 5% 楼板。重算失败时窗口为空，不回退快照缓存。
- 折现率：`max(10%, ceil(该企业报告币种十年期国债收益率) + 6)`，再夹到 0–50（`policyDiscountRate()`）。有限数（含 0 和负值）都算观测，只有缺失才回退 10% 并标 `RATE_FALLBACK`。港币报告币种代理美元十年期；人民币不用美债。公式全市场同一条，不为单只股票定制。显示货币不改折现率。当前已提交快照缺少经核验的报告币种，因此港股回退报价港币，人民币官方折现率是 10%，美元与港币是 11%（美元十年期 4.85，asOf 2026-11-25），已对齐的 A/H 组在工件上大约差 1 个百分点；这是数据缺口，不是给某对上市写了不同规则，也不应把这 1 个百分点当成要保留的政策特征。
- 区间：同一模型把折现率上下浮动 2 个百分点，并把起始增速围绕已经约束过的发布起点上下浮动 2 个百分点，再裁剪到 [0, min(15%, g*)]（`POLICY_V1.band`）。发布起点已在该上限上时，乐观增速不再抬高，区间宽度主要来自折现。不对稳健正增长一律纳入 0% 增速；负历史不把高端发明为 15%；体制不确定时低端再纳入终值 0。金融机构的端点也是 `residualIncomeValue`。头条 `mid` 是发布居中点估计，不是不对称包络的算术中点；终值占比 `terminalShare` 一并披露。
- 现金口径核对：只对一般公司，取最近三个财年 `free_cash_flow_per_share` 都为正时的中位数，套用同一组窗口、折现率和终值假设算 `presentValue`。少于三年或任一年非正数为空；与采用的官方基数相差 25–49% 加 `CASH_DIVERGENCE`（仍发布，且仍以盈利侧为主）；对称差距 50%–200% 且两边都能形成正估值时，公开值取两套估值的中点，标 `CASH_MIDPOINT`，区间覆盖两边；大于 200%（约三倍）以 `CASH_UNRECONCILED` 拒绝发布。金融机构的剩余收益路径不用现金流中点。
- 价格：只进入安全边际；缺失给 `PRICE_MISSING`，过期给 `STALE_PRICE`，都不改内在价值；基本面过期给 `STALE_DATA` 也不拒绝出值。
- 一致性：`buildDefaults()` 与 `policyValue()` 对同一快照给出同一组输入（EPS、官方增速、终值增速、折现率、两段窗口），由 `tests/unit/policy.test.js` 的默认输入对齐用例锁住；页面默认参数与发布值文件因此不会分叉。
- 自选、对比与方法页读发布值文件；股票页按同一组默认输入在本地计算（seed 对齐测试锁住），不再显示重复的发布值面板。刷新与校验见 `POLICY.md`。
