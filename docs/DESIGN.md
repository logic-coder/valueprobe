# 设计说明

目标：一个能在 GitHub Pages 上跑起来的开源估值工具页，读起来像产品、用起来像仪表盘。

## 原则

1. **数字优先**。估值结论先于参数。宽屏将公允价与保守情景并排，参数和财务证据随后。
2. **克制的色彩**：中性灰阶 + 单一强调色（绿）。红只用于亏损/危险，黄只用于警告；没有品牌色块堆叠。
3. **双主题**：`prefers-color-scheme` 跟随系统，页头可手动切换并记忆；所有颜色走 `:root` 变量。
4. **可读的密度**：13–14px 正文、表格 12.5px、数字等宽；行距与分组靠留白，不靠边框。
5. **可访问**：可见焦点环、`aria-label` 按钮、对比度达标、移动端单列并保留全部操作。

## 结构

- 首页 `/` 将搜索作为主操作。固定展示三个跨市场示例。有自选或最近记录时，最多展示五条续看入口，自选优先。页面内嵌工商银行估值示例。
- 股票页 `/stock/:symbol/dcf`：
  - 固定页头包含品牌、股票搜索和自选、比较、语言、货币、主题入口。选择搜索候选后直接打开个股。
  - 股票条：公司名、代码、交易所、原币报价。
  - 工作区是单屏：头条是发布口径下的 ValueProbe 公允价；改假设后对照带内左右并列默认价与试算价。随后是安全边际、更紧假设的毛估估对照、完整试算参数，以及财务趋势图。历史研究入口在方法页，不作为个股页的单独标签。
  - 旧的六标签路径 `/stock/:symbol/:tab`（摘要 / 图表 / 财务数据 / 大师交易 / 股东研究等）重定向到 `/dcf`，避免旧链接失效。
- 自选 `/watchlist`：本机列表，带默认内在价值与安全边际、JSON/CSV 进出。
- 比较 `/compare`：最多五支、按安全边际排序、可回放的查询串。
- 关于 `/about`：来源、次序、许可、贡献与安全入口。
- 页脚：一行品牌说明 + 署名/许可入口。

移动端（≤640px）头部只留图标入口、货币字段收窄；表单单列、成长窗口上下堆叠、结果条前置，
列表页头部换行、表格保持横向滚动并给滚动阴影。

## 实现约束

- 公式内核零改动；视觉全部通过 CSS 变量与组件 class，不动数值。
- Quasar 组件保留（表单、菜单、对话框），但外观由 `src/styles/theme.css` 与 `components.css` 接管。
- 颜色仅出现在 `:root` 变量表；新增颜色先加变量。危险文字用 `--danger-text`，不用裸红。
- 大依赖延后：图表组件与 echarts 在面板靠近视口时才挂载。
- 图标用 Material Icons 离线条目；品牌 mark 为内联 SVG（`App.vue`），favicon 同源。
- 本机状态统一走 `lib/storage.js`：localStorage 被禁用时退化为内存，页面不能因持久化失败白屏。
- 可访问性是门禁：`axe`（wcag2a/aa，深浅两主题）在 e2e 里跑；对比度取样由 `npm run audit:contrast` 自起预览验。浏览器门禁在 PR 时由 Actions 跑，数据推送时本地跑。
- **数据契约**：`public/data/` 的季度快照是线上唯一的基本面事实源。每股收益、自由现金流、有形账面价值、历史增速、可预测性**不提供在线编辑**，只能本地 `npm run snapshot` 后提交推送；现价与估值假设（折现率、增长率、永续、年限、目标倍数）可在线调整。12 倍现行利润是固定对照，不能改，也不进入内在价值（公开口径）或自选。手动模式是全部数据源失败时的兜底，才允许改基本面。不要给基本面字段加 inline 编辑器——见 README「Data contract」。
- 规范链接：`index.html` 的 canonical 与 OG 用 `__SITE_URL__` 占位，构建时由 `VITE_SITE_URL` 注入绝对地址（Pages 工作流按仓库生成）。
- 静态托管自保：构建把 `index.html` 复制成 `404.html`（深链回落到 SPA）；旧壳引用已删 chunk 时，`vite:preloadError` 带 `_r` 标记整页重载一次，成功启动后清掉标记，更新后的部署仍能再次自愈。

## 已知取舍

- 表格在窄屏横向滚动，不做卡片化重排（列语义强，重排反而难对齐）；比较页只保留价格/内在价值/安全边际，
  倍数让位。
- 强调色在深色主题下提亮（`#34d399`），安全边际等小字改走 `--accent-strong` 过 AA。
- 无动效库：只有 0.2s 的宽度/颜色过渡，避免廉价感。

## 估值试算与首屏阅读

个股结果栏以公开估值为锚，使用同一工作报价比较默认、盈利承压及组合压力下的安全边际。图条共享 ±100% 的刻度，超出时按端点绘制并保留实际百分比。普通公司显示支撑报价所需的起始盈利增速，金融模型显示报价相对有形账面的倍数。默认态下，默认价是独立的主数字，区间与口径说明在右侧；用户修改模型假设后，对照带内左右并列默认价与试算价；窄屏按现有规则层叠。历史研究入口放在方法页，研究下载及原始数据不会增加个股页的网络请求。
